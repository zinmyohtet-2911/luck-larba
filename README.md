# 💱 Luck Larba — Currency Exchange App

A simple React currency exchange calculator that converts Myanmar Kyat (MMK) into Thai Baht (THB), Chinese Yuan (CNY), and US Dollar (USD) in real time.

## 📖 About

This project is a beginner-friendly React app built to practice **controlled inputs**, **state management**, and **real-time calculation**. When a user types an amount in the MMK field, the other three currency fields update automatically based on fixed exchange rates.

## ✨ Features

- Real-time currency conversion as you type
- Converts MMK → THB, CNY, USD
- Clean and responsive UI
- Rounded to 2 decimal places
- Handles empty input gracefully (no NaN errors)
- Read-only output fields to prevent accidental edits

## 🛠️ Built With

- [React](https://react.dev/) (Vite / CRA)
- CSS3 (Flexbox)
- JavaScript (ES6+)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or later)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/luck-larba.git

# Navigate into the project
cd luck-larba

# Install dependencies
npm install

# Start the development server
npm run dev
